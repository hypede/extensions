# HypeDE extensions

https://extensions.hypede.xyz — extensions that come with HypeDE and notes on
using GNOME extensions in a HypeDE session. Plain HTML served by GitHub Pages;
`CNAME` holds the domain.

The catalog (`catalog/`, `ru/catalog/`) lets people create an account and
publish their own extensions and themes; every upload is checked by an
antivirus and by a moderator. Its API lives in `server/` — see
`server/README.md` for running and deploying it.
